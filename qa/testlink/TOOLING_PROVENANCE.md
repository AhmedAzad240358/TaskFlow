Adapted from https://github.com/Seganation/unishare/tree/main/qa on 26 October 2026:
Dockerfile, docker-compose.yml, setup.sh, overlay/, scripts/load.py and scripts/report.py.
The reference README and team prompts informed the workflow. The reference rawa_testdata.py
was inspected in /tmp for its Python data structure only. No reference tests, requirements,
member data files or database seed were copied into this repository.

The three seed SQL files are generated by setup.sh from the upstream TestLink 1.9.20
schema/default-data/UDF files, with prefix markers removed and database name set to testlink.
The Debian archive URLs, patched XML-RPC class, AJAX step reorder patch, CSRF web
requirements import, cookie login and navigation before printing are retained.
